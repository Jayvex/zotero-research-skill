## 概述

Zotero Research Skill 是一个为 Claude Code 设计的 Zotero 文献管理技能，支持从文献调研到论文写作的全流程科研工作流。

### ✨ 主要功能

- 🔍 **智能文献检索**：支持关键词搜索、全文搜索、多条件过滤
- 📄 **论文阅读与分析**：获取论文详情、提取全文内容
- 📚 **引用管理**：列出收藏夹、标签管理
- 📊 **引用分析**：查找引用、参考文献、相关文献
- 🔄 **批量操作**：批量获取项目、分页查询

### 🛠️ 技术栈

- **命令行工具**：pyzotero
- **API**：Zotero 本地 API（端口 23119）
- **语言**：Python 3.8+
- **平台**：Windows、macOS、Linux

## 配置说明

### 📍 API 配置

#### 本地 API（推荐）

- **地址**：`http://localhost:23119/api/`
- **优点**：无需 API 密钥、速度快、支持读写
- **要求**：Zotero Desktop 正在运行

#### Web API

- **地址**：`https://api.zotero.org/`
- **优点**：无需 Zotero Desktop、支持远程访问
- **要求**：需要 API 密钥和 Library ID

### 🔑 获取 API 密钥（Web API）

1. 访问 https://www.zotero.org/settings/keys
2. 登录您的 Zotero 账户
3. 点击 "Create new private key"
4. 为密钥命名（如：zotero-research-skill）
5. 选择权限（建议选择全部权限）
6. 点击 "Save Key"
7. 复制生成的 API 密钥

### 📚 获取 Library ID（Web API）

1. 访问 https://www.zotero.org/settings/keys
2. 您的 Library ID 在页面顶部显示

### ⚙️ 配置 pyzotero

pyzotero 使用环境变量进行配置：

```bash
# 设置 API 类型（local 或 user）
export ZOTERO_API_TYPE=local

# 设置 Library ID（Web API）
export ZOTERO_LIBRARY_ID=12345

# 设置 API 密钥（Web API）
export ZOTERO_API_KEY=your_api_key_here

# 设置 Library 类型（user 或 group）
export ZOTERO_LIBRARY_TYPE=user
```

## 基本功能

### 🔍 搜索文献

#### 基础搜索

```bash
# 搜索关键词
pyzotero search -q "machine learning"

# 限制返回数量
pyzotero search -q "machine learning" --limit 10

# JSON 格式输出
pyzotero search -q "machine learning" --json
```

#### 高级搜索

```bash
# 全文搜索（包括 PDF 内容）
pyzotero search -q "methodology" --fulltext

# 按项目类型过滤
pyzotero search -q "climate change" --itemtype journalArticle

# 按收藏夹过滤
pyzotero search -q "test" --collection ABC123

# 按标签过滤
pyzotero search -q "topic" --tag "climate" --tag "adaptation"

# 分页查询
pyzotero search -q "topic" --limit 20 --offset 20 --json
```

#### 搜索技巧

1. **使用引号搜索短语**
   ```bash
   pyzotero search -q '"machine learning"'
   ```

2. **使用多个关键词**
   ```bash
   pyzotero search -q "federated learning privacy"
   ```

3. **使用全文搜索**
   ```bash
   pyzotero search -q "deep learning" --fulltext
   ```

### 📄 获取项目详情

```bash
# 获取单个项目
pyzotero item ABC123

# JSON 格式输出
pyzotero item ABC123 --json

# 获取多个项目
pyzotero subset ABC123 DEF456 GHI789

# 获取子项目（附件、笔记）
pyzotero children ABC123

# 获取全文内容
pyzotero fulltext ABC123
```

### 📚 管理收藏夹和标签

```bash
# 列出所有收藏夹
pyzotero listcollections

# 列出所有标签
pyzotero tags --json
```

## 高级功能

### 📊 引用分析

> 注意：以下命令需要论文的 **DOI**，不支持 Zotero KEY。且不支持 `--json` 参数。

#### 查找引用

```bash
# 查找引用给定论文的论文（需要 DOI）
pyzotero citations --doi "10.1109/JIOT.2023.1234567"

# 限制返回数量
pyzotero citations --doi "10.1109/JIOT.2023.1234567" --limit 50
```

#### 查找参考文献

```bash
# 查找给定论文引用的参考文献（需要 DOI）
pyzotero references --doi "10.1109/JIOT.2023.1234567"

# 限制返回数量
pyzotero references --doi "10.1109/JIOT.2023.1234567" --limit 50
```

#### 查找相关文献

```bash
# 查找相关文献（需要 DOI）
pyzotero related --doi "10.1109/JIOT.2023.1234567"

# 限制返回数量
pyzotero related --doi "10.1109/JIOT.2023.1234567" --limit 30
```

#### Semantic Scholar 搜索

```bash
# 在 Semantic Scholar 上搜索
pyzotero s2search -q "machine learning"

# 按年份过滤
pyzotero s2search -q "climate change" --year 2020-2024

# 按引用数排序
pyzotero s2search -q "deep learning" --sort citations --min-citations 100
```

### 🔧 其他功能

#### 列出项目类型

```bash
pyzotero itemtypes
```

#### DOI 索引

```bash
# 输出 DOI 到 Key 的映射
pyzotero doiindex

# 查找所有 DOI
pyzotero alldoi
```

## 常见问题

### ❓ Q: 如何安装 pyzotero？

**A**: 使用 pip 安装：
```bash
pip install pyzotero
```

如果遇到问题，尝试：
```bash
pip install --user pyzotero
pip install pyzotero -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### ❓ Q: 为什么连接失败？

**A**: 可能原因：
1. Zotero Desktop 未运行 → 启动 Zotero Desktop
2. 端口被占用 → 检查端口 23119 是否被其他程序占用
3. 防火墙阻止 → 检查防火墙设置

### ❓ Q: 如何搜索所有文献？

**A**: 使用空字符串作为查询：
```bash
pyzotero search -q "" --limit 1000
```

### ❓ Q: 如何获取 PDF 全文？

**A**: 首先获取子项目，然后获取全文：
```bash
# 获取子项目
pyzotero children ABC123

# 获取全文（如果有附件）
pyzotero fulltext ATT456
```

### ❓ Q: 如何按时间排序？

**A**: pyzotero 不直接支持时间排序，但可以获取所有项目后手动排序：
```bash
pyzotero search -q "topic" --json
```

### ❓ Q: 如何导出 BibTeX？

**A**: pyzotero 不直接支持 BibTeX 导出，但可以：
1. 在 Zotero Desktop 中导出
2. 使用 Zotero Web API
3. 手动转换 JSON 格式

## 故障排除

### 🔧 连接问题

**问题**：`Connection refused`

**解决方案**：
1. 检查 Zotero Desktop 是否运行
2. 检查端口 23119 是否开放
   ```bash
   netstat -an | grep 23119
   ```
3. 测试 API 连接
   ```bash
   curl -s "http://localhost:23119/api/users/0/items?limit=1"
   ```

### 🔧 搜索问题

**问题**：`No results found`

**解决方案**：
1. 尝试更广泛的搜索词
2. 使用全文搜索
   ```bash
   pyzotero search -q "keyword" --fulltext
   ```
3. 检查文库是否有内容
   ```bash
   pyzotero search -q "" --limit 10
   ```

### 🔧 编码问题

**问题**：`UnicodeEncodeError`

**解决方案**：
1. 设置环境变量
   ```bash
   export PYTHONIOENCODING=utf-8
   ```
2. 使用 JSON 格式输出
   ```bash
   pyzotero search -q "keyword" --json
   ```

### 🔧 权限问题

**问题**：`Permission denied`

**解决方案**：
1. 使用 `--user` 参数安装
   ```bash
   pip install --user pyzotero
   ```
2. 检查 Zotero API 权限
