## 使用示例（嵌入式/IoT 方向）

```markdown
# ARM vs RISC-V 嵌入式架构 IoT 技术映射 — 文献笔记

## 基本信息
- **作者**：Facelo, Mapandi, De Mesa 等
- **年份**：2026
- **期刊**：Int'l Journal of Education, Research, and Innovation Perspectives
- **DOI**：10.5281/zenodo.21216177
- **Zotero Key**：TX52KTIQ

## 一、研究概述
系统综述（PRISMA 2020），从五大数据库筛选 184 篇文献，纳入 28 篇，
对比 ARM 和 RISC-V 在 IoT 嵌入式场景的性能、生态和选型策略。

## 二、核心发现
### ARM 架构
- 性能基准：1.25–2.14 DMIPS/MHz，生态最成熟
- 70% 开发者优先选择 ARM
- Cortex-M0/M3/M4/M7/M33 覆盖全场景

### RISC-V 架构
- 自定义扩展可实现 12–17% 周期缩减
- 开源免授权费，但工具链仍在追赶

### ESP32 平台
- 集成 Wi-Fi/BLE，TCP 吞吐量 12–15 Mbps

## 三、技术映射框架
1. 计算性能 — DMIPS/MHz、CoreMark
2. 能效比 — 功耗/性能比
3. 生态系统 — 工具链、社区、文档
4. 安全机制 — TrustZone、MPU、加密引擎
5. 应用需求 — 实时性、无线连接、成本

## 四、对 STM32 学习的启示
- STM32（Cortex-M）在工业 IoT 中仍是主流
- RISC-V 适合定制指令集场景，学习曲线较陡
- 选型先明确需求，再匹配架构

## 五、局限性与未来方向
- 缺少实际功耗对比数据
- RISC-V 在安全认证（如 IEC 61508）方面的进展需要跟踪
```
