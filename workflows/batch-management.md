# 批量管理工作流

## 使用场景
当用户需要大规模文献组织和管理时使用此工作流。

## 工作流程

### 步骤1：现状分析
**目标**：统计文献数量和分布，识别未分类文献

**操作**：
1. **获取库概览**
   ```bash
   pyzotero search -q "" --limit 1000 --json
   pyzotero listcollections
   pyzotero tags --json
   ```

2. **统计文献数量**
   - 总文献数
   - 按年份分布
   - 按类型分布
   - 按标签分布

3. **识别未分类文献**
   ```bash
   pyzotero search -q "" --limit 1000 --json
   ```
   > 获取所有文献后，手动筛选没有标签的条目。

4. **分析标签使用情况**
   ```bash
   pyzotero tags --json
   ```

### 步骤2：批量操作
**目标**：执行批量标签、批量移动等操作

**操作**：
1. **批量添加标签**
   > pyzotero 不支持批量添加标签。请在 Zotero Desktop 中选择多个条目后统一添加标签。

2. **批量移动到收藏夹**
   > pyzotero 不支持批量移动条目。请在 Zotero Desktop 中拖拽条目到目标收藏夹。

3. **批量更新元数据**
   - 批量更新年份
   - 批量更新作者
   - 批量更新摘要

### 步骤3：质量检查
**目标**：检查重复文献，验证元数据完整性

**操作**：
1. **检查重复文献**
   - 基于标题相似性
   - 基于DOI匹配
   - 基于作者+年份组合

2. **验证元数据完整性**
   - 检查必填字段
   - 验证格式正确性
   - 识别缺失信息

3. **修复损坏链接**
   - 检查PDF附件
   - 验证外部链接
   - 修复断开的引用

### 步骤4：报告生成
**目标**：生成库统计报告，输出管理建议

**操作**：
1. **生成统计报告**
   ```markdown
   # 文献库统计报告

   ## 总体统计
   - 总文献数：150
   - 有PDF附件：120 (80%)
   - 有标签：100 (67%)
   - 有笔记：50 (33%)

   ## 年份分布
   - 2024年：30篇
   - 2023年：45篇
   - 2022年：35篇
   - 其他：40篇

   ## 标签使用
   - federated-learning：25篇
   - edge-computing：20篇
   - privacy：15篇
   ```

2. **输出管理建议**
   - 建议添加标签的文献
   - 建议移动到收藏夹的文献
   - 建议删除的重复文献

3. **提供优化方案**
   - 标签体系优化
   - 收藏夹结构优化
   - 元数据补全建议

### 步骤5：执行与确认
**目标**：执行建议的操作，确认操作结果

**操作**：
1. **显示操作预览**
   ```markdown
   📋 即将为以下10篇文献添加标签"review"：
   1. 论文标题1 (KEY1)
   2. 论文标题2 (KEY2)
   ...
   确认操作？(y/n)
   ```

2. **执行批量操作**
   - 分批执行（每批10篇）
   - 显示进度
   - 记录操作日志

3. **确认操作结果**
   - 验证操作成功
   - 报告失败项
   - 提供重试选项

## 示例交互

**用户请求**：
```
帮我整理文献库，添加统一的标签体系
```

**Skill响应**：
1. 分析现有标签体系
2. 建议统一标签方案
3. 批量添加标签
4. 生成整理报告
5. 提供后续维护建议

## 输出示例

```markdown
# 文献库整理报告

## 操作摘要
- 批量添加标签：50篇
- 批量移动到收藏夹：30篇
- 删除重复文献：5篇
- 修复元数据：10篇

## 详细操作

### 批量添加标签
✅ 成功：45篇
⚠️ 部分成功：3篇（权限不足）
❌ 失败：2篇（条目不存在）

### 批量移动到收藏夹
✅ 成功：30篇

### 删除重复文献
✅ 成功：5篇（已移动到回收站）

## 后续建议

### 标签体系优化
1. 建议使用统一的标签命名规范
2. 建议创建标签层级结构
3. 定期清理未使用的标签

### 收藏夹结构优化
1. 按研究主题创建收藏夹
2. 按论文类型创建子收藏夹
3. 定期整理和归档

### 元数据补全
1. 为10篇文献补充摘要
2. 为5篇文献补充DOI
3. 为15篇文献补充作者信息
```
